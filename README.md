# 🤖 בוט טריילים לאינסטגרם

הבוט רץ בענן של GitHub לפי שעון, בחינם, גם כשהמחשב כבוי. הוא לא משתמש ב-Claude ולא צורך טוקנים.

## מה הוא עושה
1. **כל 4 שעות (סנכרון):** מושך מאינסטגרם את כל הרילז והנתונים שלהם (צפיות ועוקבים), ומודד את הטריילים שעלו.
2. **3 פעמים ביום (09:00, 14:00, 20:00):** לוקח את הסרטון הבא בתור מבין אלה שעבדו, שם עליו אות קטנה בקצה המסך, ומעלה אותו כ-Trial Reel עם אותו התיאור.
3. **כשסרטון נשחק:** טרייל שקיבל פחות מחצי מהצפיות של הטוב ביותר שלו, או שעלה כבר 5 פעמים, עובר לסבב עריכה. בכל סבב הבוט מוסיף זום קל, האצה קלה, חיתוך של ההתחלה ושינוי צבע קטן. אחרי 3 סבבים הסרטון פורש.
4. **הדשבורד:** הקובץ `DASHBOARD.md` מתעדכן אחרי כל ריצה. רואים אותו מהטלפון באפליקציית GitHub.

## הגדרות שאפשר לשנות (`config.json`)
| הגדרה | ברירת מחדל | מה זה |
|---|---|---|
| `enabled` | true | false כדי לעצור הכל |
| `auto_top_n` | 20 | כמה סרטונים מובילים לקחת אם `sources.txt` ריק |
| `min_days_between_reposts` | 3 | כמה ימים לחכות לפני שאותו סרטון עולה שוב |
| `max_posts_per_generation` | 5 | אחרי כמה העלאות לעבור לעריכה בכל מקרה |
| `burn_ratio` | 0.5 | ירידה מתחת לחצי מהשיא נחשבת "נשחק" |
| `max_generations` | 3 | כמה סבבי עריכה לפני שסרטון פורש |
| `graduation` | SS_PERFORMANCE | טרייל שמצליח עובר לעוקבים אוטומטית (MANUAL = נשאר טרייל) |

את שעות ההעלאה משנים ב-`.github/workflows/post.yml`. השעות שם הן לפי UTC, כלומר שעון ישראל פחות 2 בחורף או פחות 3 בקיץ.

**לבחור סרטונים ידנית:** מדביקים קישורים ב-`sources.txt`, קישור בכל שורה.

## הקמה חד-פעמית (בערך 20 דקות)
1. **GitHub:** פותחים חשבון ב-github.com ויוצרים ריפו **פרטי** (Private) בשם `trial-bot`, ומעלים אליו את הקבצים.
2. **טוקן של אינסטגרם:**
   - נכנסים ל-developers.facebook.com ← My Apps ← Create App.
   - בוחרים במקרה השימוש של Instagram, ואז "API setup with Instagram login".
   - לוחצים **Generate token** ליד החשבון, מתחברים לאינסטגרם ומאשרים. מעתיקים את הטוקן.
3. **שמירת הטוקן ב-GitHub:** בריפו נכנסים ל-Settings ← Secrets and variables ← Actions ← New repository secret.
   - Name: `IG_TOKEN`
   - Value: הטוקן שהעתקתם
4. **התראות לטלפון (לא חובה):**
   - בטלגרם שולחים ל-@BotFather את `/newbot`, ושומרים את הטוקן שמתקבל כ-secret בשם `TELEGRAM_BOT_TOKEN`.
   - שולחים הודעה כלשהי לבוט החדש. את ה-ID שלכם (מקבלים אותו מ-@userinfobot) שומרים כ-secret בשם `TELEGRAM_CHAT_ID`.
5. **הפעלה:** בלשונית Actions מאשרים את ה-workflows.
   - מריצים ידנית את **sync stats** (Run workflow).
   - אחר כך מריצים ידנית את **post trial reel** כדי לראות שהטרייל הראשון עלה.
   - מכאן הכל רץ לבד.

הבוט מחדש את הטוקן לבד כל שבוע ושומר אותו מוצפן, כך שלא צריך לגעת בו שוב.
